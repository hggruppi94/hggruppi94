## 📌 Featured Projects

### 🖥️ [PA Command Center](https://github.com/hggruppi94/pa-command-center)
All-in-one automation toolkit for Process Assistants — audit automation, real-time rate tracking, idle time detection, web dashboard, and auto-generated shift summaries with Slack integration.

`Python` `Selenium` `Flask` `Pandas` `Slack API`

### 📊 [Trans_Charge Visualizer](https://github.com/hggruppi94/transcharge-tracker)
Standalone HTML dashboard for visualizing transshipment and charge data. Interactive stacked bar charts, work pool filters, and hourly breakdowns — all in a single file, no server required.

`JavaScript` `HTML/CSS` `Chart.js`

### 📦 [HOU6 Tote Command Center](https://github.com/hggruppi94/HOU6-tote-command-center)
Excel-based tote inventory management system. Tracks totes across 5 floors, calculates demand from staffing inputs, and prescribes pallet movements with surplus/deficit analysis.

`Excel` `Advanced Formulas` `Data Modeling`

### 🤖 [Apollo Audit Automation](https://github.com/hggruppi94/apollo-audit-automation)
Selenium-based automation for SWACE Pick Audits. Handles the full audit lifecycle — question navigation, response capture, auto-submit, session recovery, and multi-format exports.

`Python` `Selenium` `ChromeDriver`

### 🧮 [MPI Tote Demand Calculator](https://github.com/hggruppi94/mpi-tote-demand-calculator)
Tampermonkey userscript that injects a real-time tote demand calculator onto the FCLM portal. Scrapes live data, calculates per-floor demand, and prescribes pallet movements.

`JavaScript` `Tampermonkey` `DOM Scraping`
